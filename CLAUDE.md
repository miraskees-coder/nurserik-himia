# Правила разработки NURSERIK CHEMISTRY

Платформа для изучения химии и исследования развития критического мышления (магистерская диссертация Хуантхана Нурсерика). Публикуется на GitHub Pages по адресу `/nurserik-himia/`.

## Сборка и проверка

- `node build.mjs` — собирает страницы из `src/` в `index.html`, `research/`, `trainer/`, `kinetics/`. Собранные файлы коммитятся: Pages публикует ветку `main` как есть.
- `node --test tests/engine.test.mjs` — юнит-тесты движка задач (без браузера).
- `node tests/browser.mjs` — браузерные тесты через Chrome DevTools Protocol. Chrome должен быть установлен.
- После любого изменения в `src/` — пересобрать и прогнать оба набора тестов.

## Переводы

- Весь видимый текст в HTML пишется маркером `⟦қазақша‖русский‖english⟧`, в атрибутах — `aria-label="⟦…‖…‖…⟧"`.
- В JS используется `L(kk, ru, en)` или тройка `[kk, ru, en]`.
- Сборка падает, если в русском тексте есть казахские буквы или в английском — кириллица. Числа в маркерах тоже пишутся по-разному: `0,5` в kk/ru и `0.5` в en.
- `toLocaleString` не используется: числа форматируются функциями `fmt` / `NCEngine.N`.

## Честность и данные

- Не показывать нереализованную функцию как работающую. Статусы на главной обновлять вместе с кодом.
- Не выдавать подготовленные правила и примеры за генеративный ИИ.
- Не показывать вымышленных учеников, оценки или исследовательские результаты.
- Модель с упрощениями подписывается прямо на странице (единицы, допущения).
- Никаких секретов в репозитории. В клиент попадает только публичный `anon`-ключ Supabase.
- Ученики — несовершеннолетние: собирать минимум данных. Исследовательские наборы — только под псевдонимом.

## Химия и задачи

- Каждый шаблон в `src/trainer/engine.js`: генерация по seed, проверка `valid`, эталон, допуск, типичные ошибки, лишнее данное, проверочные вопросы.
- Новый шаблон обязательно добавить в `tests/engine.test.mjs`, в функцию `reference()` с независимым пересчётом.
- Формулы и допущения моделей описаны в `docs/CHEMISTRY_MODELS.md`.

## Стиль кода

- Чистый JS (ES5-совместимый стиль в браузерных файлах), без зависимостей. Каждый интерактив запускается внутри `safe("имя", fn)`.
- Цвета — только через CSS-переменные из `src/site/site.css`; светлая и тёмная темы обязательны.
- Перед крупными изменениями — тег или ветка `backup/...`.
