## 2. Архитектура (без смены стека)

- Остаётся чистый JS + `build.mjs` + GitHub Pages. Новые страницы: `/lab/` (каталог) и `/lab/<id>/` (лаборатория). Каждая лаборатория — отдельная страница, поэтому тяжёлые симуляции не грузятся с главной.
- **Единый шаблон лаборатории** (`src/lab/template.js`) — 16 разделов из промпта собраны в 6 экранов:
  1. Подготовка: тема, цель, теория, оборудование, безопасность.
  2. Прогноз.
  3. Опыт: симуляция и выбор параметров.
  4. Таблица наблюдений и график.
  5. Анализ: вопросы трёх уровней, ответы скрыты до своей попытки.
  6. Вывод и сохранение.

  Повтор опыта, сравнение запусков и черновик (`localStorage` + синхронизация после подключения базы) встроены в шаблон.
- **Описание лаборатории — данные** (`src/lab/labs/<id>.js`): метаданные на 3 языках, параметры с допустимыми диапазонами, функция модели, вопросы, критерии. Каталог строится из этих описаний автоматически, поэтому в каталоге не может быть «пустых» карточек.
- Каждая модель документируется в `docs/CHEMISTRY_MODELS.md` и покрывается юнит-тестами.

## 3. Кинетика 10 класса: модели конкретных реакций

Числа в лабораториях будут следовать из **расчётной модели выбранной реакции**: численное интегрирование кинетического уравнения с фиксированным шагом, детерминированно. Частицы — только визуализация, их движение согласовано с моделью.

Коэффициенты — **учебные**, это прямо указано на странице и в таблице данных.

| Лаб. | Реакционная система | Кинетическая модель | Что видит ученик |
|---|---|---|---|
| L1 | Na₂S₂O₃ + 2HCl → 2NaCl + S↓ + SO₂ + H₂O | Учебная модель: v = k·[S₂O₃²⁻] в избытке кислоты; время «исчезновения креста» t — до накопления заданного количества S | Таблица C → t, 1000/t; график v(C); вывод о порядке по тиосульфату |
| L1* | 2H₂O₂ → 2H₂O + O₂ (катализатор) | Первый порядок по H₂O₂ | Объём O₂(t); сравнение с L1: зависимость не обязана быть линейной |
| L2 | Те же системы | k(T) по Аррениусу с учебной Eₐ; связанный график распределения энергии | Время при 20/30/40 °C; γ из своих данных |
| L3 | CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑ | Гетерогенная: v ∝ S·[HCl]; S кусков и порошка по размеру частиц; масса CaCO₃ и HCl по стехиометрии | Убыль массы m(t), объём CO₂; закон сохранения массы |
| L4 | 2H₂O₂ (без / MnO₂ / каталаза) | Разные k при одинаковой ΔH; энергетический профиль с Eₐ и Eₐ(кат) | Кривые V(O₂), энергетическая диаграмма |
| L5 | Таблицы C(t) из модели или введённые учеником | — | Средняя скорость на интервалах, обоснование, проверка единиц |
| L6 | Выбор из L1–L4 | — | План опытов, серия запусков, сравнение, вывод; задачи с недостаточными и противоречивыми данными |

Все расчёты пройдут юнит-тесты: стехиометрия и сохранение массы, монотонность, контрольные точки по аналитическому решению для 1-го порядка.

## 4. Аккаунты, сохранение, кабинет учителя — **нужно согласование**

- **Supabase:** Auth + PostgreSQL + Row Level Security; схема — в `docs/DATABASE.md`.
- Ученик регистрируется **только по коду класса**. Собираются отображаемое имя, класс и язык. Согласие родителей отмечает учитель.
- Роли хранятся только в базе; админ назначается вручную.
- Черновики пишутся в `localStorage` и синхронизируются при входе; при потере связи показывается сообщение.
- **Кабинет учителя:**
  - классы, коды приглашения, назначение лабораторной работы со сроком;
  - таблица «ученик / работа / дата / балл / попытки / ошибки / статус», проверка открытых ответов;
  - экспорт: CSV для Excel и PDF через печатный шаблон — без тяжёлых библиотек.
- **Диаграммы** показывают только реальные данные. Если данных нет — «Данные пока отсутствуют».
- **Что нужно от автора:** создать проект Supabase, прислать Project URL и `anon`-ключ; подтвердить порядок получения согласий в школе.

## 5. Режим «Демонстрация на уроке»

Кнопка в каждой лаборатории (клавиша `D`):

- полноэкранный режим, формулы и подписи ×1,5, скрыты второстепенные панели;
- большие кнопки «Пуск / Пауза / Сброс / Объяснение / Скрыть ответ»;
- быстрый переход к соседней лаборатории;
- сценарий урока: объяснение → прогноз учеников (ответ скрыт) → опыт → обсуждение.
