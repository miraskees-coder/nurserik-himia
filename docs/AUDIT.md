# Аудит репозитория — этап 1

Дата: 7 ноября 2026. Резервная точка: тег `backup-v1-before-platform` (опубликован на GitHub).

## Что было на момент аудита

Один статический сайт-урок «Химическая кинетика, 10 класс» (15 слайдов), опубликованный через GitHub Pages из ветки `main`.

| Компонент | Состояние | Комментарий |
|---|---|---|
| Сборка `build.mjs` | Работает | Собирает один `index.html` из `src/`. Без зависимостей. |
| Переводы | Работают | Маркеры `⟦kk‖ru‖en⟧` → `data-i` + массивы `I18N`. Сборка проверяет, что в RU нет казахских букв, а в EN нет кириллицы. |
| Реакционная камера | Работает | 2D-модель упругих столкновений, термостат, поршень, катализатор. Энергия активации задана в **приведённых единицах** (Eₐ = 7 / 3,5), а не в кДж/моль. |
| Графики | Работают | SVG: C(t), Максвелл–Больцман (интегрирование методом Симпсона), энергетическая диаграмма, порядки реакций. |
| Калькуляторы | Работают | Вант-Гофф, Аррениус (2 режима), закон действующих масс. |
| Лабораторный журнал | Работает | 1000/t, линейная регрессия, R². |
| Задачи | Статические | 12 задач A–C с решениями в `<details>`. Генератора вариантов нет. |
| Тест | Работает | 15 вопросов; правильные ответы лежат в клиентском коде. Для самопроверки это допустимо, для контроля — нет. |
| Аккаунты, прогресс, ИИ | Отсутствуют | Хранения данных нет; язык сохраняется в `localStorage`. |
| Тесты | Вне репозитория | Браузерный прогон (29 проверок) лежал во временной папке. |
| SEO | Есть | meta, JSON-LD, sitemap, подтверждение Google Search Console, IndexNow. |

## Найденные проблемы и риски

1. **Монолитная страница.** 230 КБ загружаются целиком, включая все 15 слайдов. Для одного урока это приемлемо, для платформы — нет.
2. **Нет светлой темы и режима доступности.** Урок только тёмный.
3. **Ответы теста в клиенте.** Их можно увидеть в исходном коде. Для контрольного режима проверка должна идти на сервере.
4. **Единицы модели.** В камере Eₐ указана без единиц. Нужно явно написать «приведённые единицы модели».
5. **Источник учебника** (Оспанова и др.) указан по памяти — его надо сверить с реальным изданием.
6. **Тесты не в репозитории**, поэтому их нельзя запустить повторно.
7. **GitHub Pages — статический хостинг.** Аккаунты, роли, ИИ и исследовательские данные требуют внешнего бэкенда.
8. **Несовершеннолетние пользователи.** Нужны минимизация данных, согласие родителей и псевдонимизация в исследовательских наборах.

## Что сохраняется без изменений

Весь учебный контент урока, камера, графики, калькуляторы, журнал, задачи, тест, словарь и система переводов. Урок переехал по адресу `/kinetics/`. Старые ссылки вида `/#14` автоматически ведут на соответствующий слайд.
