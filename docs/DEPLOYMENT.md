# Публикация

## Сейчас: GitHub Pages (статическая часть)

1. Измените исходники в `src/`.
2. Выполните `node build.mjs`, затем `node --test tests/engine.test.mjs` и `node tests/browser.mjs`.
3. Закоммитьте исходники **и** собранные файлы (`index.html`, `research/`, `trainer/`, `kinetics/`) и отправьте в `main`.
4. Pages настроен так: *Settings → Pages → Deploy from a branch → `main` / root*. Обновление появляется через 30–60 секунд.

Адреса работают внутри базового пути `/nurserik-himia/`. Все ссылки относительные (`../trainer/`), поэтому сайт открывается и с GitHub Pages, и с локального сервера. Клиентского роутинга нет: каждая страница — отдельная папка с `index.html`, поэтому прямые ссылки и обновление страницы работают.

Старые ссылки на урок (`/nurserik-himia/#14`) перенаправляются на `/nurserik-himia/kinetics/#14`.

### Поисковые системы

- **Google Search Console:** подтверждение — meta-тег на главной. Sitemap: `sitemap.xml`.
- **Bing и Яндекс:** IndexNow, ключ — файл `47c73971016c77459af016e4687a01ee.txt` в корне. После добавления страниц отправьте их адреса POST-запросом на `https://api.indexnow.org/indexnow`.

## Следующий этап: Supabase (аккаунты, прогресс, исследование)

Требуются действия владельца проекта:

1. Создать проект на supabase.com (бесплатный тариф).
2. Передать разработчику **только** `Project URL` и `anon public key`. Они публичны и попадут в код сайта. **Не передавать и не коммитить** `service_role` key и пароль базы данных.
3. В *Authentication → Providers* оставить вход по e-mail. Регистрация учеников — по коду класса от учителя (подробнее в `DATABASE.md`).
4. Применить миграции из `supabase/migrations/` (появятся на этапе 3) через SQL Editor или `supabase db push`.
5. Роль `admin` назначается вручную SQL-запросом владельца — никогда через интерфейс регистрации.

## ИИ-наставник (этап 7)

- Ключ LLM API хранится только в секретах Supabase Edge Function (`supabase secrets set ...`).
- В браузер ключ не попадает. Функция проверяет авторизацию, лимиты запросов на ученика и класс и записывает факт использования ИИ.
- До подключения на странице тренажёра отображается статус «ИИ-тәлімгер қосылмаған / ИИ-наставник не подключён».
