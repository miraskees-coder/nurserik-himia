# Химические и физические модели платформы

Классификация моделей:

- **концептуальная** — показывает идею качественно;
- **расчётная** — числа следуют из формулы при заданных учебных коэффициентах;
- **эмпирическая** — подтверждена измерениями.

На платформе пока нет эмпирических моделей.

## 1. Реакционная камера (`src/kinetics/chamber.js`) — концептуальная

- 2D-модель частиц-дисков с упругими столкновениями; массы A, B = 1, AB = 2, K = 4.
- Реакция A + B → AB происходит при условии 0,5·|v_отн|² > Eₐ. Eₐ = 7, с катализатором — 3,5. Это **условные единицы модели**, а не кДж/моль; на странице это подписано.
- Термостат: дисперсия скорости σ² = 1 + t/25 (t — температура в °C). Мягкое перемасштабирование скоростей к целевой средней энергии.
- Поршень: целевой объём V = V₀/p.
- Масса и стехиометрия сохраняются: каждое событие убирает одну A и одну B и создаёт одну AB; импульс сохраняется.
- Ограничения: 2D, нет обратной реакции, тепловой эффект не моделируется, числа не сопоставимы с реальным экспериментом.

## 2. Модель газа на главной (`src/site/hero-gas.js`) — расчётная

- 2D упругие диски, приведённые единицы: m = 1, k·300 K = 1. Eₐ = 3·kT(300 K).
- Теория: для 2D-газа доля частиц с кинетической энергией выше E равна e^(−E/kT). Модель показывает измеренную долю рядом с теоретической.
- Доля в модели флуктуирует из-за малого числа частиц (70) и усредняется экспоненциальным скользящим средним с постоянной времени около 2,5 с.

## 3. Графики урока (`src/kinetics/charts.js`) — расчётные

| График | Формула | Параметры |
|---|---|---|
| C(t) | C = e^(−0,05t) | средняя скорость — наклон хорды, мгновенная 0,05·e^(−0,05t) |
| Максвелл–Больцман | f(E) = 2/√π · (kT)^(−3/2) · √E · e^(−E/kT) (3D) | доля выше Eₐ — интегрирование методом Симпсона, n = 800 |
| Энергетическая диаграмма | учебные значения: Eₐ = 80, ΔH = −40 кДж/моль; с катализатором Eₐ = 40 | иллюстрация, не конкретная реакция |
| Порядки реакции | C₀ = 1, k = 0,035 | t½: 14,3 / 19,8 / 28,6 с |
| Активность фермента | 2^((T−37)/10) / (1 + e^((T−40,7)/2)) | качественная форма: оптимум около 37 °C, денатурация выше |

## 4. Калькуляторы урока — расчётные

- Вант-Гофф: v₂/v₁ = γ^((t₂−t₁)/10).
- Аррениус: ln(k₂/k₁) = (Eₐ/R)(1/T₁ − 1/T₂), R = 8,314 Дж/(моль·К), T = t + 273,15.
- Закон действующих масс: только для элементарных реакций. Твёрдые вещества не входят в уравнение; давление ×n умножает концентрацию каждого газа на n.

## 5. Движок задач (`src/trainer/engine.js`) — расчётный

| Шаблон | Уровень | Формула | Диапазоны | Лишнее данное |
|---|---|---|---|---|
| `avg_rate` | A | v = \|ΔC\|/Δt | C 0,2–2,0 моль/л, шаг 0,05; Δt 20–120 с или 1–5 мин | температура |
| `vh_ratio` | A | γ^(Δt/10) | γ 2–4, Δt 10–40 °C, ответ ≤ 300 | концентрация |
| `vh_gamma` | B | γ = (v₂/v₁)^(10/Δt) | γ ∈ {2, 3, 4}, Δt ∈ {20, 30} | время реакции |
| `vh_time` | B | τ₂ = τ₁ / γ^(Δt/10) | τ₁ 8–54 мин, τ₂ ≥ 0,25 мин | концентрация |
| `mass_action` | B | v₂/v₁ = Π(nᵢ^aᵢ) | 4 элементарные реакции, n ∈ {2, 3, 4} | температура |
| `arr_ratio` | C | e^((Eₐ/R)(1/T₁ − 1/T₂)) | Eₐ 40–90 кДж/моль, ответ 1,2–50 | множитель A |
| `arr_ea` | C | Eₐ = R·ln(k₂/k₁)/(1/T₁ − 1/T₂) | T 290–330 K, k₂/k₁ ∈ {2, 3, 4, 5} | концентрация |
| `half_life` | C | t½ = ln2/k; C/C₀ = e^(−kt) | t½ 10–40 мин | C₀ (для 1 порядка не нужна) |

**Проверка ответа:**

- относительный допуск 1–2 %;
- эквивалентные единицы принимаются (мин ↔ с, кДж ↔ Дж, моль/(л·с) ↔ моль/(л·мин));
- единица другой размерности отклоняется;
- распознаются типичные ошибки: линейное вместо степенного, °C вместо K, lg вместо ln, забытый перевод единиц, неверный порядок реакции и другие.

**Автотесты** (`tests/engine.test.mjs`): по 1500 вариантов на шаблон.

- эталон совпадает с независимым пересчётом;
- генерация воспроизводима по seed;
- верный ответ принимается в любом языке и в эквивалентных единицах;
- типичные ошибки не засчитываются;
- контрольные значения: 15,625; 1,924; 53,59 кДж/моль; 8; 9; 30 мин; 0,005 моль/(л·с);
- в русских текстах нет казахских букв, в английских нет кириллицы.

**«Решения ИИ»** — заранее подготовленные учебные варианты. Примерно в 40 % случаев решение верное, в остальных содержит ошибку одного из типов: формула, единицы, вычисления, данные, химическое допущение, обобщение. Тест проверяет, что ошибочное решение действительно отличается от эталона.
